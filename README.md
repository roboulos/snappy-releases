# Snappy for macOS — releases

Download the newest Snappy: **https://snappy.ai/download** (a redirect to [Snappy.zip on the latest release](https://github.com/roboulos/snappy-releases/releases/latest/download/Snappy.zip)).

Each release holds the notarized `Snappy-<version>.zip`, its SHA-256, and `appcast.xml`, the feed Snappy reads to update itself (Sparkle 2). The source is private. This repository holds release files only; nothing else.
