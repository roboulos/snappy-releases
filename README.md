# Snappy for macOS — releases

Download the newest Snappy: **https://download.snappy.ai** (or [Snappy.zip on the latest release](https://github.com/roboulos/snappy-releases/releases/latest/download/Snappy.zip)).

Each release holds the notarized `Snappy-<version>.zip`, its SHA-256, and `appcast.xml`, the feed Snappy reads to update itself (Sparkle 2). The source is private; this repository holds release files only.

`download/` is the Cloudflare Worker behind download.snappy.ai: a redirect to the latest release's `Snappy.zip`.
